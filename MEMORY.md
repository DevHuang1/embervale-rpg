The control implementation is therefore moving to a deterministic map-space pointer command model that preserves player-facing click controls without relying on fragile preview pick behavior.

- A final live browser check sent a cursor movement command through the upgraded UI and received the completion message “You reach the place your lantern marked,” confirming click-to-move remains functional alongside inventory and class systems.
- Error investigation found a blank Babylon canvas in both preview and production while the HUD remained healthy. TypeScript and production builds succeed, the canvas has a working WebGL2 context, and no runtime exception is reported. The leading diagnosis is that the full-screen overlay’s dark pseudo-element vignette is visually masking the scene; this will be reduced and split into a non-obscuring frame layer.
- Disabling the overlay pseudo-elements in the live preview did not reveal the forest, eliminating the HUD vignette as the primary cause. The rendering fault is therefore inside scene creation or render-loop startup rather than CSS stacking.
- Direct scene inspection confirms that the render loop is active, the storybook camera is active and ready, and 157 meshes are present; however, `scene.isReady()` remains false. The blank canvas is therefore caused by one or more scene assets failing Babylon readiness checks rather than a missing camera or stalled render loop.
- Every procedural mesh is blocked on an unready StandardMaterial effect. The floor material has no effect key or compiled effect after many frames, which identifies missing shader-side-effect registration in the modular Babylon import path as the scene readiness root cause.
- The correct StandardMaterial shader pair is `default.vertex` and `default.fragment`. Registering those modules explicitly restored the forest scene in the live preview, and the browser console now reports no active errors.
- The streamlined player overlay now shows warmth, the active Cinder Warden class, level, and a one-tap Satchel control. Browser testing confirmed the Satchel opens a focused drawer with inventory, item-use actions, and retained class skills while leaving the forest visible.
